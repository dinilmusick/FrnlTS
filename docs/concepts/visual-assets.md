# Visual Assets

A Component may contain multiple Visual Assets.

A Visual Asset represents rendered content and may represent text, an image, SVG, color, shape, icon, gradient, or another renderable form.

Assets expose editable properties. Examples include content/type, position, origin, translation, rotation, scale, opacity, tint/color, and per-asset clipping.

The property model is extensible. FRNL does not require a fixed exhaustive list of visual properties.

Visual Assets are visual structures, not interaction owners. Events belong to the Component.
