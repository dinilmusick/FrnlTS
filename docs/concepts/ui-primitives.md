# UI Primitives

A UI Primitive is the basic reusable UI unit defined using FRNL semantics.

Examples include Button, Text Input, Checkbox, and Text.

A primitive owns its Bounds, Visual Assets, Events, and States.

## Composition

UI Primitive
- Bounds
- Visual Assets
- Events
- States

FRNL defines the concepts and contracts. Concrete primitive definitions are authored by Theta-Engine.
