# Phases

A State executes through three phases:

1. Attack
2. Sustain
3. Release

## Attack

Attack has a finite explicit duration. Property Curves are stretched or compressed to that duration.

## Sustain

Sustain has no duration property. Property Curves loop over their canonical one-second domain while the State remains sustained.

## Release

Release has a finite explicit duration. Property Curves are stretched or compressed to that duration.

The phase owns duration semantics; the Curve does not.
