# FRNL-TS Documentation

FRNL-TS is the frontend semantic framework counterpart to KrnlTS.

FRNL defines the generic concepts and contracts used to define UI primitives and their behavior. It does not store concrete UI primitives; Theta-Engine uses FRNL to author them, and Floks stores the resulting concrete definitions.
